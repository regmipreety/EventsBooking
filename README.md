**Events Booking**
Events Booking is a web application built with ASP.NET Core MVC for browsing events, creating bookings, and managing users and vendor profiles.

**Features**
View available events
Create and manage bookings
Apply booking rules such as capacity and duplicate prevention
Manage user and vendor-related information
Uses SQLite as the database
Tech Stack
ASP.NET Core MVC
Entity Framework Core
SQLite
Razor Views
Prerequisites
.NET 10 SDK
**Getting Started**
Clone the repository
Navigate to the project folder:
cd WebApplication1
Restore dependencies:
dotnet restore
Run the application:
dotnet run
Open the local URL shown in the terminal
**Project Structure**
Controllers: Handles app routes and actions
Models: Contains data models and view models
Views: Razor UI pages
Data: Database context and migrations
Services: Business logic and validation rules
Configuration
The application uses SQLite by default. You can update the connection string in the appsettings.json file if needed.
